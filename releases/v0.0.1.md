# Capybara Camp v0.0.1

The first public release: a native macOS board and chat for local Codex and Claude Code conversations.

## Included

- Local profile discovery and import, with separate source identities
- Kanban columns, search, provider/profile filters and persisted board positions
- Chat continuation through existing Codex and Claude Code CLI logins
- Streaming replies for Camp-started turns, mid-turn steering and persistent prompt queues
- Per-session model, effort and supported speed settings, including Codex Ultra Fast where available
- Live Claude Code activity and read-only subagent transcripts
- Automatic discovery of new sessions and immediate open-transcript file notifications
- Full-height message rendering, readable long responses and scroll-position preservation
- A generated capybara mascot and a self-contained HTML setup guide

## Install

Download `Capybara-Camp-0.0.1-macos-universal.zip` and `SHA256SUMS`. Verify the checksum, extract the ZIP and move the app to Applications. Requires macOS 14+, Python 3.11+ and the relevant provider CLI installed and signed in. Apple silicon and Intel are included in the same bundle.

This preview is ad-hoc signed, not Apple-notarized. macOS may block downloaded copies. See the [setup guide](https://teslashibe.github.io/capybara-camp/) for source-build instructions and Apple's guidance.

## Limits

Camp-started conversations are chat-only: tools, hooks and MCP servers are disabled. Independently running terminal sessions update as their CLI saves messages; their live token stream is not attached. Close an externally owned session before sending through Camp.

Account-login management, usage dashboards, automatic account switching, cross-provider handoff and provider-native dictation are not part of v0.0.1. External runtime monitoring currently covers Claude Code. Access to models and speed tiers depends on the provider account.

## Validation

The local suite includes 49 Python tests and 40 native checks. Manual checks covered Codex and Claude continuation, steering and queues, long transcripts, new-session discovery, file replacement, SQLite WAL updates and preservation of drafts and reading position.

Gitleaks 8.30.1 reported no secrets in the staged source or release archive. The public source and packaged app were also reviewed for credentials and private local data before publication. Local verification logs, real transcripts and private screenshots are excluded from the repository and release.
